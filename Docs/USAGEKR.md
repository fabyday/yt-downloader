# 상세 사용법

[한국어 소개](READMEKR.MD) · [English README](../README.md) · [빌드](BUILD.md)

## 기능

- 동영상 다시보기·업로드 영상의 MP4/HLS 미리보기와 구간 다운로드
- 현재 재생 위치 앵커와 긴 영상 이동 중 표시
- 시작/끝 지점 마킹
- 한 영상에서 여러 구간을 목록으로 추가해 순차 저장
- 원본 유지, H.264 MP4, Premiere ProRes, DaVinci DNxHR 출력 프리셋 선택
- 설정 뷰와 다운로드 큐 뷰 분리
- KawaiUI 기반 Panel, Input, Select, Tabs, Switch, Badge, Progress UI
- 한국어, 영어, 일본어 UI와 앱 내 언어 전환
- 큐 패널 클릭으로 URL, 선택 구간, 화질, 속도, 인코딩 프리셋 복원
- 복원한 큐에 새 구간만 추가하고 완료 구간은 중복 다운로드에서 제외
- 앱 종료 시 큐와 구간별 완료 상태를 저장하고 yt-dlp 부분 파일부터 자동 재개
- 앱 실행마다 공식 최신 안정판 yt-dlp 확인 및 자동 업데이트
- 메인·큐 창 공통 커스텀 타이틀바와 메뉴 제거 (Windows 오른쪽 창 버튼, macOS 왼쪽 신호등 버튼)

### 치지직 지원 범위와 로그인

- `https://chzzk.naver.com/video/숫자` 주소를 입력하면 네이티브 플레이어에서 미리보기,
  구간 선택, 큐 저장 및 기존 출력 프리셋을 사용할 수 있습니다. MP4를 우선 선택하고
  HLS 다시보기는 앱에 포함된 hls.js로 재생합니다. 재생 가능한 H.264/AAC가 필요합니다.
- 일부 다시보기에서 yt-dlp의 DASH `sourceURL` 오류가 발생하면, 앱에 포함한 치지직 전용
  호환 플러그인이 같은 재생 목록의 정상 MP4 포맷으로 대체합니다. 미리보기와 다운로드에
  공통 적용하며, MP4가 없거나 DRM으로 보호된 포맷은 이 대체 경로로 처리하지 않습니다.
- 생방송(`/live/`) 녹화와 클립 전용 주소, 그 외 사이트는 아직 지원하지 않습니다.
  현재 편집기는 길이가 정해진 영상용이므로 라이브 주소에는 별도 안내를 표시합니다.
- 공개 영상은 쿠키 없이도 이용할 수 있으며, 저장한 쿠키가 있으면 함께 적용합니다. 로그인·성인 인증이 필요한 영상에는 해당 계정의
  유효한 인증과 시청 권한이 필요합니다. 쿠키 가져오기는 권한 우회가 아니며, 유료 혜택이나
  화질 향상·광고 제거를 이 다운로더에서 보장하지 않습니다.
- **환경설정 → 쿠키 → 치지직**을 선택하고, 치지직에 로그인한 브라우저 프로필을 고릅니다.
  브라우저를 완전히 종료한 뒤 추출하거나 Netscape 형식의 `cookies.txt`를 가져옵니다.
  네이버 로그인 쿠키 `NID_AUT`·`NID_SES`와 치지직 도메인 쿠키만 보관합니다.
  해당 쿠키는 계정 자격 증명이므로 다른 사람에게 공유하지 마세요.
- YouTube와 치지직은 저장 파일·작업별 스냅샷·삭제가 분리되어 있습니다. 한쪽을 가져오거나
  삭제해도 다른 쪽은 유지됩니다. 네이버 쿠키는 YouTube 미리보기 세션에 넣지 않습니다.
  UI는 로그인 쿠키의 **존재**만 표시하며 서버에서 인증 성공을 검증했다는 뜻이 아닙니다.
- 확인 자료: [yt-dlp 치지직 구현](https://github.com/yt-dlp/yt-dlp/blob/master/yt_dlp/extractor/chzzk.py),
  [네이버 성인 인증 안내](https://help.naver.com/service/30044/contents/24620?lang=ko&osType=COMMONOS),
  [yt-dlp 쿠키 안내](https://github.com/yt-dlp/yt-dlp/wiki/FAQ#how-do-i-pass-cookies-to-yt-dlp).


### YouTube 쿠키 설정

설정 → **쿠키** 탭에서 로그인한 브라우저를 선택하고 **쿠키 받아오기**를
누릅니다. 프로필 선택기는 기본 브라우저 경로의 프로필 이름을 자동 검색합니다.
YouTube에 로그인한 프로필을 선택하거나 **자동 선택**을 사용할 수 있습니다.
**다시 검색**으로 목록을 갱신하고, 검색되지 않는 경우 폴더 이름을 직접 입력할 수도 있습니다.
목록 조회는 이름 메타데이터만 읽으며 쿠키 추출이나 키체인 접근을 실행하지 않습니다.
브라우저가 실행 중이어도 추출 버튼을 누를 수 있습니다. 클릭 시 실행 상태를 다시 확인하고,
실행 중이면 완전 종료 안내 팝업을 표시합니다. 종료한 뒤 **다시 확인 후 추출**을 누르세요.
팝업은 브라우저를 강제 종료하거나 종료 감지 후 자동으로 추출하지 않습니다.
Chrome, Edge, Firefox, Brave, Chromium,
Opera, Vivaldi 및 macOS Safari를 지원합니다. 설치·로그인된 브라우저를 선택해야 합니다.
DB 잠금 오류가 나면 브라우저를 완전히 종료하고 재시도하세요. Windows 브라우저 암호화로
직접 추출이 막히면 Firefox 또는 **파일에서 가져오기**로 Netscape 형식의 `cookies.txt`
(1MB 이하)를 사용할 수 있습니다. [쿠키 내보내기 안내](https://github.com/yt-dlp/yt-dlp/wiki/Extractors#exporting-youtube-cookies).
직접 추출은 yt-dlp가 브라우저 전체 쿠키를 임시 파일로 내보낸 뒤 필요한 도메인만 필터링합니다.
임시 전체 쿠키 파일은 성공·실패 시 모두 정리하며 원본 브라우저 쿠키는 변경하지 않습니다.
YouTube·Google 관련 유효한 쿠키만 Worker 사용자 데이터 폴더에 로컬 파일로 저장합니다.
저장 위치는 `downloader-auth/youtube-cookies.txt`이며 Electron 자체의 `Cookies` DB와 분리됩니다.
쿠키는 로그인 정보이므로 공유하거나 Git에 추가하지 마세요.

가져오기와 **쿠키 삭제**는 즉시 저장됩니다. 이후 시작하거나 재시도하는 다운로드에
적용되며 실행 중인 작업은 기존 쿠키 사본을 사용합니다. 작업 종료 시 사본을 제거합니다.
파일을 가져왔다고 로그인 성공이 보장되지는 않으며, 인증 만료 시 다시 가져와야 합니다.
가져온 YouTube 쿠키는 앱 전용 미리보기 세션에도 복사됩니다. 도구 모음의 ‘쿠키 저장됨’은 인증 성공을 의미하지 않습니다.
이미 열려 있는 영상은 선택 구간을 유지하고 다시 불러옵니다. 쿠키 삭제 시 미리보기 인증도 해제됩니다.
미리보기 중 변경·삭제된 쿠키는 다운로드용 원본 저장소에 덮어쓰지 않습니다. Google 및 다른 사이트 쿠키를 미리보기로 전달하지 않습니다.
임베드 오류 또는 15초간 메타데이터 미응답 시 저장된 쿠키로 yt-dlp에 다시 요청합니다.
접근이 허용되고 호환되는 HTTPS H.264/AAC 스트림이 있으면 내부 플레이어로 전환합니다.
쿠키 만료·접근 거부·호환 스트림 없음·재생 실패는 미리보기 영역에 구분해 표시합니다.
쿠키로 모든 HTTP 403 또는 PO Token 오류가 해결되지는 않습니다.

설정 → 앱 정보에서 yt-dlp 시작 시 자동 업데이트의 확인·다운로드·완료·실패 상태를 볼 수 있습니다.
**yt-dlp 업데이트 확인**으로 앱을 재시작하지 않고 다시 확인할 수 있습니다.
진행 중인 다운로드는 기존 버전을 유지합니다. **앱 릴리스 자동 확인**은 앱 자체의 릴리스
조회 설정이며, yt-dlp 자동 업데이트와는 별개입니다. FFmpeg는 앱에 포함된 버전을 사용합니다.


## 단축키

- `Alt`를 누르면 휠 확대·축소가 가능한 시간 눈금/탐색 바 영역에 테두리가 표시됩니다. 키를 떼거나 창을 벗어나면 숨겨집니다.
- `Space`: 재생/정지
- `A`: 시작 지점 찍기
- `S`: 끝 지점 찍기
- `Q`: 구간 내 이동 — 플레이헤드를 선택 구간 안으로 제한합니다. 끝에서는 정지하고, 구간 반복을 켜면 시작으로 돌아갑니다.
- `W`: 구간이 따라가기 — 플레이헤드가 시작보다 앞서면 시작점을, 끝보다 뒤로 가면 끝점을 영상 길이 안에서 확장합니다.
- `E`: 자유 이동 (기본) — 구간 선택과 독립적으로 플레이헤드를 이동하고 재생합니다.
- `←` / `→`: 1초 이동
- `Shift + ←` / `Shift + →`: 큰 이동 단위만큼 이동 (기본 10초)

설정 → 단축키에서 각 키를 변경하거나 기본값으로 복원할 수 있습니다. 중복 키는 저장하지 않습니다.
macOS의 Command(`⌘`)와 Control(`⌃`)은 별개로 설정됩니다. 예를 들어 `⌘S`와 `⌃S`는 다른 단축키입니다.
중복 지정 시 편집 중인 항목과 기존 할당 항목이 빨간 테두리로 표시됩니다.

## 구간 선택 규칙

- 시작/끝 지정 단축키와 ‘현재 위치’ 버튼: 끝점을 시작점보다 앞에 찍으면 영상 시작부터
  새 끝점까지, 시작점을 끝점보다 뒤에 찍으면 새 시작점부터 영상 끝까지 재설정합니다.
- 선택자와 시간 숫자를 마우스로 드래그할 때는 경계를 넘으면 반대 선택자를 함께 밀어
  이동합니다. 항상 `0 ≤ 시작 ≤ 끝 ≤ 영상 길이`를 유지합니다.
- 선택자가 화면에서 겹칠 만큼 가까워지면 시작 태그는 오른쪽, 끝 태그는 왼쪽을 향하는
  화살촉 형태로 나타납니다. 화살표 문자가 아닌 태그 외곽선 자체로 방향을 표시합니다.
  원하는 태그를 잡아 드래그해 분리하며, 태그도 해당 선택자를 따라 이동합니다.
  태그를 누른 순간 시간은 바뀌지 않고, 양 끝에서는 태그가 화면 안에 머뭅니다.
- 구간 내 이동 모드에서 드래그한 선택자가 플레이헤드를 잡으면 재생을 일시정지하고,
  드래그 방향을 바꾸어도 놓을 때까지 함께 이동합니다. 놓은 위치에 머물며 자동으로
  반복 시작점으로 돌아가지 않습니다. 자유 이동/구간 따라가기 모드에는 적용하지 않습니다.
- 길이 0인 선택은 편집 상태로 허용하지만 구간 목록에 추가할 수 없습니다.
- 시작·끝이 밀리초 단위로 같은 구간은 중복으로 추가하지 않습니다. 일부만 겹치는
  구간은 허용합니다. 중복 안내는 목록 중앙에 1초 표시되며 포커스·재생을 변경하지 않습니다.
  목록이 숨겨져 있다면 안내를 볼 수 있도록 목록만 펼칩니다.

## 출력 모드

기존 원본 유지/H.264/ProRes/DNxHR 외에 H.265 MP4, VP9 WebM, 무손실 FFV1 MKV,
MP3, 24-bit PCM WAV, FLAC 프리셋을 지원합니다. 인코딩 속도와 대상 편집기의 코덱 지원은 다를 수 있습니다.

다운로드 → 출력 모드를 **수동 FFmpeg 옵션**으로 바꾸면 프리셋 선택이 비활성화됩니다.
선택해 둔 프리셋의 옵션과 컨테이너를 가져온 뒤 수정할 수 있으며, 큐에도 함께 저장됩니다.
입력 예: `-c:v libx264 -crf 20 -preset medium -pix_fmt yuv420p -c:a aac -b:a 192k`

전체 명령어가 아니라 출력 옵션만 입력합니다. 앱이 입력 파일, 선택 시간, 출력 경로를 관리합니다.
코덱/품질/비트레이트/프레임레이트/픽셀 형식/오디오 채널 및 제한된 `-vf` 필터
(`scale`, `fps`, `format`, `crop`, `pad`, `hflip`, `vflip`, `transpose`, `setsar`)를 허용합니다.
추가 `-i`, 출력 경로, 스크립트, 외부 파일을 읽는 필터는 허용하지 않습니다.
코덱과 컨테이너 조합은 FFmpeg가 지원해야 하며, 호환되지 않으면 인코딩 단계에서 오류가 표시됩니다.

다운로드는 권리가 있거나 허용된 콘텐츠에만 사용하세요.
